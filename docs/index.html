Hi! I'm connected to two (pretend) Teslas. Ask me about battery, charging, temperature — or tell me to start charging the Model Y.

The real app answers from your actual cars via the official Tesla Fleet API, runs commands (charging, preconditioning, sentry) through a strict allowlist, and can plug into a local LLM (Ollama) or any OpenAI-compatible service for free-form questions. Vehicle data goes only to the backend you choose.
